# Reporting a security issue

Report suspected vulnerabilities in Reader, its desktop installers, update delivery or
this public repository through [GitHub private vulnerability reporting](https://github.com/lwtlab/reader/security/advisories/new).
The repository's maintainers receive the report privately.

Include the affected version, operating system, architecture, steps to reproduce and
the expected impact. Prefer a small synthetic example. Remove credentials, account
identifiers and personal document content from supporting material.

Do not place vulnerabilities, tokens, private application source, personal libraries
or unredacted logs in public issues, pull requests or attachments. Ordinary questions
and feature requests can use public issues after removing personal information.

If a credential may have been exposed, its owner should revoke or rotate it at the
issuing service; deleting a file or Git commit does not revoke a credential. Never
include the credential itself in a public report or test it against another person's account.

## 安全问题报告

请通过上方的 GitHub 私密漏洞报告入口提交 Reader、桌面安装包、更新交付或本仓库的
安全问题。提供版本、系统、架构和经过脱敏的复现步骤，优先使用合成示例。
请勿在公开 Issue、PR 或附件中提交密钥、个人文档、私有源码和未脱敏日志。
